# homebrew-tap

Homebrew tap for GRIDWATCH command-line tools.

## Usage

```sh
brew tap gridwatch/tap
brew install gridwatch/tap/<tool>
```

## Maintenance

Every formula and cask in this repository is written by the release workflow of the tool it installs. Nothing here is edited by hand: a change to how a tool installs belongs in that tool's repository, and the next release rewrites the entry here.
